# 🚀 Kişisel Portfolyo Web Uygulaması

**ASP.NET Core (.NET 10) MVC** mimarisi kullanılarak geliştirilmiş, modern, ölçeklenebilir ve tamamen yönetilebilir bir **Kişisel Portfolyo Web Uygulaması**. Proje, ziyaretçiler için dinamik bir portfolyo web sitesinden ve sezgisel bir arayüz üzerinden tam içerik yönetimi sağlayan güçlü bir yönetim (admin) panelinden oluşmaktadır.

## ✨ Öne Çıkan Özellikler

- 🎨 Modern Tek Sayfa (Single Page) Portfolyo Tasarımı
- 🔐 Güvenli Kimlik Doğrulama ve Yetkilendirme
- 📊 Kapsamlı Admin Kontrol Paneli (Dashboard)
- ⚙️ Tam Kapsamlı CRUD (Ekle/Oku/Güncelle/Sil) İşlemleri
- 📬 İletişim Mesajları Yönetimi
- ⭐ Müşteri Değerlendirmeleri ve Onay Sistemi
- 💼 Proje Yönetim Modülü
- 🛠️ Teknoloji ve Yetenek Yönetimi
- 🔗 Çoka Çok (Many-to-Many) İlişkisel Veri Yönetimi
- 📈 Kontrol Paneli Analizleri ve İstatistikler
- 📱 Tamamen Mobil Uyumlu (Responsive) Tasarım
- ⚡ Hızlı, Dinamik ve Kullanıcı Dostu Deneyim

---

## 🛠️ Kullanılan Teknolojiler

### Arka Yüz (Backend)
- **Framework:** ASP.NET Core (.NET 10) MVC
- **ORM:** Entity Framework Core (Code First)
- **Veritabanı:** MS SQL Server
- **Güvenlik:** Cookie Authentication / Identity

### Ön Yüz (Frontend)
- **Şablon Motoru:** Razor Views & View Components
- **Stil & Arayüz:** Tailwind CSS & Bootstrap 5
- **Etkileşim:** JavaScript (Fetch API & AJAX)
- **UI Bileşenleri:** SweetAlert2 & Material Symbols

---

## 📂 Mimari Yapı

Uygulama; sunum, iş mantığı ve veri erişim katmanlarını birbirinden ayıran temiz ve sürdürülebilir bir mimari izler. Veritabanı yönetiminde **Entity Framework Core Code First** yaklaşımı kullanılmış olup, gelecekteki geliştirmeler için esneklik ve ölçeklenebilirlik sağlar.

---

## 🎯 Proje Vurguları

- Temiz, okunabilir ve sürdürülebilir kod mimarisi
- Ölçeklenebilir veritabanı tasarımı
- Güvenli kimlik doğrulama altyapısı
- Modern ve şık UI/UX tasarımı
- Tüm cihazlarda kusursuz çalışan responsive yapı
- Yönetim paneli üzerinden kolay ve anlık içerik güncelleme

---

**ASP.NET Core (.NET 10) MVC, Entity Framework Core ve Tailwind CSS kullanılarak geliştirilmiştir.**
