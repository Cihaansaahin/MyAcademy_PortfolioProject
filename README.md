## 🛠️ Teknolojik Mimari & Mimari Desenler

* **Framework:** .NET 10 (ASP.NET Core MVC)
* **ORM & DB:** Entity Framework Core (Code-First), MS SQL Server
* **Veri Yönetimi:** Eager Loading (`Include`), LINQ, AsNoTracking
* **Güvenlik:** ASP.NET Core Identity (Role-Based Access Control)
* **UI & Styling:** Tailwind CSS, Bootstrap 5, Material Symbols
* **Yapı:** ViewComponents, Partial Views, Custom View Models

---

## ✨ Öne Çıkan Özellikler

* **Dinamik Hero & Banner:** Ana sayfa karşılama ekranının yönetim panelinden canlı güncellenmesi.
* **Hizmet Kataloğu:** Material Symbols ikon yapısıyla entegre dynamic CRUD işlemleri.
* **İlişkisel Veri Modeli:** Projeler ve teknolojiler (`ProjectTechStacks`) arasında Many-to-Many veri kurgusu.
* **Güvenli Yönetim Paneli:** Identity kütüphanesiyle korunan responsive admin arayüzü.
